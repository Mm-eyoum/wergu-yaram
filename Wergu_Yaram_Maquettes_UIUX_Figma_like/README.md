# Wergu Yaram — Maquettes UI/UX web

Ce pack contient les maquettes haute fidélité de la version web de Wergu Yaram, organisées comme un livrable de référence pour les développeurs.

## Pages incluses

1. Home / Portail Santé centré recherche
2. Résultats de recherche universelle
3. Détail médicament
4. Détail pathologie
5. Détail établissement de santé
6. Communauté / réseau social santé
7. Liste des besoins d’équipement
8. Tableau de bord / profil utilisateur
9. Connexion
10. Inscription
11. Article santé détaillé
12. Forum santé
13. Messages privés
14. Détail événement
15. Détail besoin / donation
16. Annuaire partenaires

## Direction UI

- Expérience centrée sur une barre de recherche santé universelle.
- Interface très simple, accueillante, épurée, inspirée de Wave.
- Palette dominante : blanc, vert/teal Wergu Yaram, bleu marine, fonds mint très légers.
- Composants : cartes arrondies, boutons verts, badges de statut, champs de recherche, filtres, onglets, sidebars contextuelles.
- Ton UX : rassurant, médical, communautaire, transparent et accessible.

## Conseils d’intégration

- Utiliser ces PNG comme référence visuelle pour reproduire les écrans dans Figma ou directement en front-end.
- Prévoir des composants réutilisables : Header, SearchBar, Card, FilterBar, ResultCard, CTAButton, Badge, SidebarPanel, StatsStrip, ProfileCard.
- Prioriser la responsivité mobile-first, même si ce pack est en version desktop.
- Maintenir la barre de recherche comme point d’entrée principal sur toutes les pages publiques.
